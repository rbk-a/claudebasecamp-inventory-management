Factory Inventory Management System

A full-stack demo: a Vue 3 single-page app talks to a Python FastAPI service over REST. There is no database. JSON files are loaded into memory at startup and filtered per request.

Data flow: changing a filter

  1. User picks a filter in FilterBarTime Period, Warehouse, Category, or Order Status. Values are written to module-level refs in useFilters.js, a singleton shared by every view.
  2. View reactsEach view watches the shared refs and calls getCurrentFilters(), which maps Period to month (e.g. 2025-09 or Q3-2025).
  3. api.js builds the requestDrops any value equal to all and sends e.g. GET /api/orders?warehouse=Tokyo&month=Q3-2025.
  4. FastAPI filters in memoryapply_filters() matches warehouse exactly and category/status case-insensitively; filter_by_month() substring-matches order_date against the month or the quarter's three months.
  5. Pydantic validates the responseList endpoints declare a response_model; summary, spending and report endpoints return plain dicts.
  6. View stores raw data in refs, derives in computedFor example allOrders and inventoryItems are refs; KPIs, chart series and table rows are computed properties that re-render automatically.

Low stock is defined as quantity_on_hand ≤ reorder_point. Pending orders are those with status Processing or Backordered. All data is 2025 sample data and is read-only at runtime.

Observations

Client calls endpoints the server does not implementapi.js defines getTasks, createTask, deleteTask, toggleTask, createPurchaseOrder and getPurchaseOrderByBacklogItem, but main.py has no /api/tasks or /api/purchase-orders routes. These would return 404/405. Tasks currently come from mock data in useAuth.js.
Reports bypasses the API clientReports.vue calls axios.get('http://localhost:8001/api/reports/...') directly instead of going through api.js, and those endpoints ignore the global filters.
Unrouted viewviews/Backlog.vue exists but has no route in main.js; backlog data is shown on the Dashboard instead.
Hardcoded valuesThe API base URL is fixed to localhost:8001, CORS allows all origins, and the quarter map only covers 2025.
